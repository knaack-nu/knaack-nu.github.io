# Knaack Nu — Super Complete Pharmacy Website

Rebuilt from the original ZIP as a coherent modern pharmacy website.

## Major changes
- Removed generic event, gift-card and appointment filler unrelated to pharmacy operations.
- Rebuilt navigation around prescriptions, refills, transfers, vaccinations, OTC catalog, delivery and pharmacist support.
- Added a 36-item demonstration OTC/wellness catalog with search, filters and saved items.
- Added dedicated category pages for pain, cold/flu, allergy, digestive care, first aid, vitamins, personal care, home health, diabetes supplies and travel health.
- Added safety, insurance, accessibility, privacy and non-emergency guidance.
- Curated/optimized pharmacy-relevant imagery and removed duplicates/unrelated assets.

## Important
All contact details, prices, service scope and product availability are demo/prototype information until verified. This site is not a diagnostic tool and should not be used for emergencies. A production pharmacy workflow must use appropriate privacy/security controls for any protected health information.
